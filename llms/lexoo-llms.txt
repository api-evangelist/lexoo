# Lexoo

> Lexoo is a commercial legal services provider that operates as an outsourced in-house legal team, focused on commercial contract review and negotiation at fixed rates per agreement with a stated maximum two-day turnaround. It also runs multi-country projects using local counsel across 70+ countries, and builds contract playbooks so client legal and sales teams can handle standard agreements themselves. Lexoo is not an API-first company — it publishes no developer portal, API documentation, or SDKs. The only machine-readable surfaces are the WordPress REST API and RSS feed exposed by its marketing site.

## APIs

- [Lexoo WordPress REST API](https://lexoo.com/wp-json/wp/v2): Standard WordPress REST API exposed by the Lexoo marketing site. Serves JSON for pages, media, taxonomies and settings. Incidental CMS surface, not a Lexoo product API.
- [Lexoo RSS Feed](https://lexoo.com/feed/): Well-formed RSS 2.0 feed. Reachable but currently carries no items — the site publishes pages only, no posts.
